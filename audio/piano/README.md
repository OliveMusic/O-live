# 그랜드 피아노 샘플

청음 트레이너가 쓰는 피아노 소리다.

- 원본: Salamander Grand Piano V3, Alexander Holm
  (https://archive.org/details/SalamanderGrandPianoV3)
- 라이선스: Creative Commons Attribution 3.0 Unported (CC BY 3.0)
  https://creativecommons.org/licenses/by/3.0/
- 받은 곳: npm 패키지 `@audio-samples/piano-mp3-velocity8` 1.0.5 (velocity 8 층, MP3)

## 바꾼 것

- A3, C4, D♯4, F♯4, A4, C5, D♯5, F♯5 여덟 음만 쓴다(파일 이름은 MIDI 번호, 57~78).
- 스테레오를 모노로 합쳤다.
- 타건 직전 4ms부터 2.4초만 남기고, 마지막 0.6초는 서서히 줄였다.
- 300Hz 위 대역의 첫 0.6초 음량이 같아지도록 음마다 크기를 맞췄다(휴대폰 스피커 기준).
- 44.1kHz 모노 96kbps MP3로 다시 저장했다.
