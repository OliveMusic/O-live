O’live는 음악 연습에 필요한 최소한의 정보만 처리합니다. 계정 연결은 선택 사항이며, 광고를 위한 추적이나 개인정보 판매를 하지 않습니다.

1. 처리하는 정보

계정 연결 없이 사용할 때

앱 설정과 청음 기록은 사용 중인 브라우저의 로컬 저장소에 보관됩니다. 이 정보는 O’live 서버로 전송되지 않으며 브라우저 데이터 삭제 시 함께 사라질 수 있습니다.

Google 계정을 연결할 때

  • Google 계정 식별자, 이메일 주소, 표시 이름 및 프로필 사진 주소
  • 청음 훈련 날짜, 정답 수 및 전체 응답 수
  • 메트로놈·튜너·스케일·트레이너·잼 세션에서 사용자가 선택한 연습 설정과 패턴
  • 중복 동기화를 방지하기 위한 임의의 동기화 식별자

O’live는 Google 비밀번호를 받거나 보관하지 않습니다. 로그인은 Google과 Supabase의 OAuth 인증 절차를 통해 처리됩니다.

2. 마이크와 오디오 처리

튜너를 사용할 때 브라우저가 마이크 권한을 요청합니다. 마이크 오디오는 음정을 계산하기 위해 사용자의 기기 안에서 실시간으로만 처리되며, 녹음하거나 서버로 전송하거나 보관하지 않습니다. 메트로놈, 트레이너와 잼 세션의 소리도 브라우저에서 생성됩니다.

3. 이용 목적

  • Google 계정으로 사용자를 식별하고 로그인 상태를 유지하기 위해
  • 날짜별 청음 점수를 저장하고 여러 기기에서 복원하기 위해
  • 사용자가 선택한 연습 설정과 패턴을 여러 기기에서 이어서 사용하기 위해
  • 계정 화면에 사용자의 이름 또는 프로필 사진을 표시하기 위해
  • 동기화 요청의 중복을 방지하고 서비스의 안정성을 유지하기 위해

4. 보관 위치와 보호

계정 인증과 클라우드 기록은 Supabase가 제공하는 인증 및 데이터베이스 서비스를 이용해 보관됩니다. 사용자별 접근 제어 정책을 적용하여 로그인한 사용자는 자신의 기록에만 접근할 수 있습니다. 인터넷을 통한 전송에는 HTTPS 암호화를 사용합니다.

5. 외부 서비스와 정보 제공

O’live는 서비스를 운영하기 위해 다음 제공자를 이용합니다.

  • Google: Google 계정 로그인 및 동의 화면 제공
  • Supabase: 사용자 인증, 로그인 세션, 청음 기록 및 연습 설정 저장
  • GitHub Pages: O’live 웹 앱과 공개 문서 제공

O’live는 개인정보를 판매하지 않으며, 위 서비스 운영 목적이나 법률상 의무가 있는 경우를 제외하고 제3자에게 제공하지 않습니다. Google에서 받은 정보의 사용과 이전은 Google API 서비스 사용자 데이터 정책과 Limited Use 요구사항을 준수합니다.

O’live는 Google 로그인과 클라우드 동기화를 제공하기 위해 아래 해외 사업자의 인프라를 이용합니다. 정보는 로그인 또는 동기화할 때 HTTPS로 암호화되어 전송됩니다. Google 계정 연결은 선택 사항이며, 국외 이전에 동의하지 않으면 계정을 연결하지 않고 기기 내 저장 방식으로 앱의 음악 연습 기능을 사용할 수 있습니다.

7. 보관 기간과 삭제

로컬 기록은 사용자가 브라우저 데이터 또는 앱 데이터를 삭제할 때까지 기기에 남습니다. 클라우드의 날짜별 청음 점수, 연습 설정·패턴 및 계정 정보는 사용자가 삭제하거나 서비스 운영상 더 이상 필요하지 않을 때까지 보관합니다. 중복 동기화 방지를 위한 개별 응답 이벤트와 임의 식별자는 생성일로부터 90일이 지나면 자동 삭제합니다.
