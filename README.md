# O'live

O'live는 연습에 필요한 도구를 하나의 차분한 화면에 담은 음악 연습 앱입니다.
설치 없이 브라우저에서 바로 사용할 수 있으며, iPhone에서는 홈 화면에 추가해
앱처럼 실행할 수 있습니다.

**[O'live 시작하기](https://olivemusic.github.io/O-live/)**

## 주요 기능

- 다양한 박자와 세분화를 지원하는 메트로놈
- 마이크로 음정을 확인하는 튜너
- 조성과 운지까지 살펴볼 수 있는 스케일 도구
- 청음 및 리듬 트레이너
- 코드 진행을 만들고 반주하는 잼 세션
- 날짜별 청음 기록, 연습 설정과 사용자 패턴의 Google 계정 동기화

## iPhone에서 사용하기

Safari에서 O'live를 연 뒤 공유 버튼을 누르고 **홈 화면에 추가**를 선택하세요.
전체 화면으로 실행되어 일반 앱처럼 사용할 수 있습니다.

수 있으며, 로그인하면 청음 기록과 연습 설정을 여러 기기에서 이어서 사용할 수 있습니다.
